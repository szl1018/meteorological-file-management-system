## ⚠️ 注意事项

1. **Mock模式限制**
   - 数据存储在内存中，刷新页面后会恢复初始状态
   - 文件不会真正上传到服务器
   - 下载不会真正下载文件
   - 删除的数据会在刷新后恢复

2. **切换到真实后端**
   - 完成后端开发后，修改 `src/mock/index.js` 中的 `ENABLE_MOCK` 为 `false`
   - 或直接删除mock相关代码

3. **浏览器控制台**
   - Mock模式下不会发送真正的API请求
   - 不会出现跨域错误
